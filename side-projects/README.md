# Side projects

Small things I built to try an idea or solve a real problem for someone close to me. This folder is the raw material for a future "Playground" section on the site.

**Nothing here is part of the site build.** Astro only builds `src/` and copies `public/`, so files in this folder are never deployed. To show one on the site, copy its build into `public/` (or link to it) as a separate, deliberate step.
